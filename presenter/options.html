ポインターと効果

ポインターの見え方と、クリック時の効果を調整します。

スポットライト

カーソル周辺を明るく、それ以外を暗く表示します。

エリアスポットライト

ドラッグで選んだ長方形の範囲を強調します。

レーザーポインター

滑らかな光の軌跡で、視線を誘導します。

左右のクリックを、色の違うリングで表示します。

手書きとズーム

手書きペンと画面ズームの動作を調整します。

手書きマーカー

ペンをONにしてドラッグで描画。トリガーキーを押している間は、クリックせずに描けます。描画中はページ操作を停止します。

画面ズーム

現在のタブの静止画を拡大します。カーソルで位置を移動し、ホイールで倍率を調整できます。Escで終了します。

ズームをONにすると、表示中のタブを撮影します。撮影画像は保存・送信しません。画面サイズを変更するとズームを終了します。

Webページで試してみましょう

通常のWebページを開き、サイドパネルのカーソルアイコンからツールを選択。
手書きは最大200画まで保持します。再読み込みで消去されます。

キーとジェスチャー

ページ内ショートカットとマウス操作を設定します。

ページ内ショートカット

Ctrl + Shift + 各キー。Webページにフォーカスがあるときに使えます。ブラウザ側が優先するキーは「Chromeのショートカット設定」で変更してください。

Chrome側の割り当てとページ内の割り当ては別です。プレゼン用の初期割り当てはS・P・Mです。レーザーは必要に応じてChrome側に登録できます。両方を変更する場合は同じキーに合わせてください。Escは、効果と描画モードを終了します。

ホイールの中ボタンを押しながら描いて、離します。Webページ上で操作してください。iframe内からのジェスチャー開始には対応しません。

Ctrl・Win・Altを使うキー操作や、矢印などの特殊キーを表示。通常の文字入力、入力欄・パスワード欄・編集中のテキストは表示しません。

使い方と設定

使い方、表示テーマ、データの管理。

表示テーマ

はじめに

  1. サイドパネル上部のカーソルアイコン（プレゼンカーソル）を選びます。
  2. 通常のWebページを開き、操作パネルで電源と使いたいツールをONにします。
  3. ページをクリックして戻り、プレゼンを開始。ペンはドラッグ、エリア強調は範囲選択、ズームはホイールで操作します。
  4. Escで表示と描画モードを終了。手書きの線は「全消去」で消せます。
  5. 電源ボタンで、クリック波紋とジェスチャーも含めて全機能OFF。手書きも消去されます。再びONにすると、波紋などの設定を復元します。

動作範囲とプライバシー

  • HTTP / HTTPSのページで利用できます。file URLはChromeの拡張詳細で「ファイルのURLへのアクセス」を許可してください。
  • Chromeの設定、新しいタブ、ウェブストア、内蔵PDFビューア、他のアプリ、デスクトップ上には表示できません。OS全体のマルチモニター描画・タスクトレイ常駐には対応しません。
  • ページ内の通常のiframeでもポインター効果とキー表示を中継します。特殊な埋め込みや変形には制限があります。動画要素自体の全画面表示には対応しません。
  • ズームは静止画です。表示中のページ操作は停止し、動画やスクロールは追従しません。権限エラー時は対象サイトへのアクセス許可を確認してください。
  • 設定はこの端末のChromeにだけ保存。手書きと撮影画像はタブのメモリだけに保持し、外部通信・解析・入力履歴の保存は行いません。

機能の参照元：hiroki-chii/cursorExtension。Chrome向けに独立して実装しています。

設定をリセット

プレゼンカーソルの色、サイズ、ショートカットを初期値に戻します。拡張機能全体のテーマは維持します。

すべての設定を初期値に戻し、各タブの効果と手書きを消去します。
