# プライバシーポリシー (Privacy Policy)

**最終更新日: 2026年11月3日**

「Tab & Bookmark Panel」（以下「本拡張機能」）は、ユーザーのプライバシーを尊重し、機密情報の保護に努めています。本ポリシーでは、本拡張機能が取り扱うユーザーデータについて説明します。

## 1. データの収集と利用
本拡張機能は、以下の目的でブラウザ内のデータにアクセスします。開発者はこれらのデータを収集しません。

- **ページコンテンツ (scripting)**: 「ページテキスト取得」機能を使用する際、アクティブなタブのテキストデータを取得して表示・コピーしますが、このデータが外部へ送信されることはありません。
- **タブおよびブックマーク情報**: 拡張機能内のパネルで表示・操作するためにアクセスしますが、これらはローカル環境でのみ動作し、外部には送信されません。

## 2. データの送信
アドレス欄の候補は、初期設定ではブラウザ内のタブ・履歴・ブックマークから取得します。「Google の検索候補」を有効にすると、文字・数字を空白で区切った複数の検索語を入力中に Google（`suggestqueries.google.com`）へ送信します。URL、単一のホスト名、履歴・ブックマークの候補一覧はこのサービスに送信しません。この設定は「ツール」でいつでも無効にできます。

アドレス欄で検索を実行した場合は、検索語を使って Google 検索（`www.google.com`）を開きます。

## 3. データの保持
本拡張機能は、ユーザーのいかなる個人情報もサーバー等に保存・保持しません。設定情報（パネルの開閉状態など）はブラウザのローカルストレージ（chrome.storage.local）に保存されますが、開発者がこれにアクセスすることはありません。

## 4. 同意
本拡張機能を利用することにより、利用者は本プライバシーポリシーに同意したものとみなされます。

# Privacy Policy (English Version)

**Last Updated: November 3, 2026**

"Tab & Bookmark Panel" (the "Extension") respects your privacy and is committed to protecting sensitive information. This policy describes how the Extension handles user data.

## 1. Data Collection and Usage
The Extension accesses browser data for the purposes below. The developer does not collect this data.

- **Page Content (scripting)**: When using the "Page Text Retrieval" feature, text data from the active tab is captured for display and copying. This data is never transmitted externally.
- **Tabs and Bookmarks**: Accessed for display and management within the Extension panel. This data stays local and is never transmitted externally.

- **Presenter Cursor** processes pointer and shortcut events locally. Zoom captures a still image of the visible tab. Captured images and drawings stay in tab memory, and tool preferences are saved in local browser storage.

## 2. Data Transmission
By default, address suggestions come from local tabs, history, and bookmarks. If you enable Google search suggestions in Tools, the Extension sends search phrases made up of words or numbers separated by spaces to Google (`suggestqueries.google.com`) as you type. URLs, single hostnames, and local suggestion lists are excluded. You can turn this setting off in Tools at any time.

When you submit a search, the Extension opens Google Search (`www.google.com`) with your search terms.

## 3. Data Retention
The Extension does not save or retain any personal information on external servers. Configuration data (such as panel states) is stored in the browser's local storage (chrome.storage.local). The developer cannot access this data.

## 4. Consent
By using the Extension, you consent to this Privacy Policy.
