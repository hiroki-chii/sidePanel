# Tab & Bookmark Panel

サイドパネルでタブとブックマークを効率的に管理し、ブラウジング体験を向上させるChrome拡張機能です。

## 🚀 主な機能

### 1. タブ & ブックマーク管理
- **直感的なサイドパネル**: ブラウザの横で常にアクセス可能な管理インターフェース。
- **ドラッグ&ドロップによるウィンドウ切り離し**: タブをパネルの背景にドロップするだけで、新しいウィンドウとして切り離せます。
- **フォルダ操作**: パネル内から直接ブックマークフォルダの作成・削除が可能。
- **レスポンシブレイアウト**: パネルの幅に応じて、詳細表示からアイコンのみのミニマル表示まで4段階（Large, Normal, Compact, Minimal）に自動で切り替わります。

### 2. YouTube 拡張ツール
- **スクロール連動ミニプレイヤー**: 動画の再生中にスクロールアウトすると、画面右下にフローティングプレイヤーを自動表示。
  - **5段階のサイズ調整**: 小（400x225）から特大（800x450）まで好みに合わせて設定可能。
  - **クイックコントロール**: プレイヤー上での再生/停止、元の位置への復帰、クローズ操作に対応。
- **サイドバー配置の固定機能**: 画面幅に関わらず、右サイドバー（おすすめ動画）を常に動画の下に回り込ませる「常に下（1カラム）」レイアウトを強制し、大画面でも没入感のある視聴環境を提供します。
- **スマートレイアウト**: サイドパネル表示中、YouTubeのおすすめ動画リストを縦並び形式に最適化し、狭い幅でも視認性を確保します。

### 3. ページコンテンツ抽出
- **Markdown/HTML形式で取得**: 現在のページ内容を瞬時にテキスト抽出。
- **プレビュー機能**: コピー前に抽出内容を確認可能。ドキュメント作成やAIへのプロンプト利用に最適です。

### 4. カスタマイズ & 快適性
- **全画面表示**: サイドパネル上部の全画面アイコンから、ブラウザウィンドウの全画面表示を切り替えます。もう一度押すと元の通常表示・最大化に戻ります。F11で切り替えた状態もボタンに反映します。
- **テーマ切り替え**: ライトモード、ダークモード、OS設定に連動するシステムモードの3種類に対応。プレゼンカーソルと詳細設定も同じテーマに連動します。
- アドレス欄の候補は、初期設定ではブラウザ内のタブ・履歴・ブックマークから取得します。「Google の検索候補」をオンにすると、空白で区切った複数の検索語を入力中に Google に送信します。URL や単一のホスト名は候補検索の対象外です。

### 5. プレゼンカーソル
サイドパネル上部のカーソルアイコン（プレゼンカーソル）から操作します。初めて使うときは、操作パネル右上の電源ボタンをオンにしてください。

- スポットライト、範囲強調、レーザー、手書きペン、静止画ズームを、表示中のWebページで使えます。
- クリック波紋、入力キー表示、中ボタンジェスチャーを個別に切り替えられます。色やサイズ、ページ内ショートカットは「詳細設定」で変更できます。
- Webページにフォーカスして `Esc` を押すと効果を終了します。手書きは「戻す」「やり直す」「全消去」で編集できます。

統合元は [Presenter Cursor for Chrome](https://github.com/hiroki-chii/cursorExtensionChrome/tree/f9b4a11df8d51b034bbd964db5d6c1d9e06e4d4c) です。

### 6. 入力モードの表示
「ツール」→「入力モードの表示位置」で「表示しない」「上」「下」「左」「右」から選べます。初期設定は「表示しない」です。設定はこのブラウザに保存され、開いている対象ページにも反映されます。

Webページのテキスト入力欄、テキストエリア、編集可能な本文で、直前に入力した文字の種類から「あ」「A」「全A」「カ」「ｶ」を推定します。入力中とIME変換中は隠れ、入力が止まって設定した時間が経つと表示されます。「入力モードの表示待機時間」で100〜5000ミリ秒を100ミリ秒単位で調整できます。初期値は700ミリ秒です。入力前、漢字などモードを判別できない入力、パスワード欄、読み取り専用欄では表示しません。キャレット座標を取得できない欄では、入力欄の端を基準にします。

補助アプリのインストールは不要です。OS側でIMEを切り替えただけでは表示は更新されません。元のWindowsアプリの仕様は [Caret Mode](https://github.com/hiroki-chii/caretExtension/tree/095153046d2e12442773b63788b6f5d6fb4d15e3) を参照してください。

## 🛠️ 技術スタック
- **Core**: Vanilla JavaScript, HTML5, CSS3
- **Chrome API**: `sidePanel`, `tabs`, `bookmarks`, `storage`, `scripting`
- **Library**: `marked.js` (Markdown プレビュー用)

## 📦 インストール方法
1. `chrome://extensions/` を開く。
2. 「デベロッパー モード」をオンにする。
3. 「パッケージ化されていない拡張機能を読み込む」を選択。
4. 本プロジェクトのルートディレクトリを選択。

## 🔒 プライバシーについて
取得したページ内容、履歴、ブックマークを検索候補サービスに送ることはありません。アドレス欄で検索を実行すると、検索語を使って Google 検索を開きます。詳しくは [プライバシーポリシー](privacy_policy.md) を参照してください。
